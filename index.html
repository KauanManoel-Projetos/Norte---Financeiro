O Chat com IA precisa do Supabase configurado

Esse assistente conversa com você usando a Claude, o que exige uma função de backend (Supabase Edge Function) guardando a chave de API em segredo. Sem isso, não dá pra fazer essa chamada com segurança direto do navegador.

Peça pro Norte te mostrar o passo a passo de configuração — depois de pronto, essa tela vira o chat automaticamente.

Ao conversar, um resumo dos seus números (não os lançamentos individuais) é enviado para gerar a resposta. Isto é orientação educativa, não é consultoria financeira profissional.
